# Florence Dushanbe — Премиальный веб-прототип цветочного бутика

Интерактивный клиентский прототип веб-сайта для **Florence Dushanbe** (Душанбе, Таджикистан), созданный креативной студией **Jomi Studio**.

## 🚀 Быстрый запуск локально

Проект уже собран и запущен на локальном сервере:

- **Локальный адрес:** [http://localhost:4173/](http://localhost:4173/)
- **В локальной сети (для проверки на смартфоне):** [http://192.168.3.28:4173/](http://192.168.3.28:4173/)

### Команды разработки:

```bash
cd florence-dushanbe

# Запуск dev-сервера с горячей перезагрузкой
npm run dev

# Сборка продакшн-бандла
npm run build

# Локальный предпросмотр продакшн-сборки
npm run preview
```

## 🎨 Дизайн и концепция

Дизайн вдохновлен эстетикой ведущих мировых флористических домов:
- **FLOWERBX** — редакционная роскошь, чистый воздух, крупная типографика (Cormorant Garamond + Cinzel) и премиальная подача.
- **Ode à la Rose** — структурированные карточки букетов, детализация состава, выбор размера букета (Классический / Премиум / Гранд Люкс).
- **Floward** — практичный e-commerce UX, фильтрация по категориям и поводам, заказ в 1 клик через Instagram Direct и WhatsApp.

### Фирменная палитра Florence:

## 📱 Реализованный функционал

1. **Главный экран (Hero):**
   - Фирменный логотип Florence Dushanbe с золотым монограмным гербом.
   - Заголовок: *«Цветы, которые говорят за вас»*.
   - Кнопки быстрого действия: «Смотреть букеты» и «Связаться с флористом».
   - Информационная полоса преимуществ: доставка от 60 минут, фото букета перед отправкой, свежие поставки, открытка в подарок.

2. **Подбор букета по поводу (Occasions):**
   - Романтика & Свидание
   - День рождения
   - Юбилей & Торжество
   - Премиум коллекция

3. **Интерактивный каталог цветов:**
   - 12 эксклюзивных букетов и композиций (французские розы White O'Hara, пионы Sarah Bernhardt и Coral Sunset, авторские шляпные коробки, подарочные сеты).
   - Фильтрация по категориям (*Все букеты, Розы, Пионы, Авторские букеты, Цветочные композиции, Подарки и сеты*).
   - Сортировка по популярности и цене.
   - Живой поиск по названию и составу цветов.
   - Избранное (Heart toggle) со счетчиком в шапке.
   - Цены указаны в таджикских сомони (сомони / TJS) с пометкой прототипа.

4. **Детальная страница букета (Product Modal):**
   - Галерея фотографий букета с переключением ракурсов.
   - Динамический выбор размера букета (*Классический, Премиум, Гранд Люкс*) с автоматическим пересчетом цены.
   - Селектор количества (+ / -).
   - Детальный состав цветов и стеблей, габариты букета.
   - Прямая кнопка **«Заказать в Instagram @florence.dushanbe»**.
   - Прямая кнопка **«Заказать в WhatsApp»** с автоматически сгенерированным текстом заказа.
   - Кнопка **«В корзину сайта»**.

5. **Интерактивная корзина заказов (Cart Drawer):**
   - Выезжающая шторка корзины.
   - Изменение количества и удаление позиций.
   - Мгновенный расчет итоговой суммы в сомони.
   - Формирование единого сообщения для заказа флористу в WhatsApp или Instagram.

6. **История бренда & Информация о бутике:**
   - Адрес: **ул. Мирзо Турсунзаде, 11, Душанбе**.
   - Часы работы: **Ежедневно 09:00 — 23:00**.
   - Прямой телефон: **+992 000 00 11 77**.
   - Доставка по Душанбе за 60-90 минут с климат-контролем и аквапаком.

7. **Лента Instagram & Отзывы:**
   - Блок социальных доказательств и ссылка на профиль `@florence.dushanbe`.
   - Отзывы гостей бутика.
